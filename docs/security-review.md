# 公开仓库前安全检查记录

检查日期：2026-10-02。范围包括导航前端、反馈 API、依赖和仓库公开内容；以下记录对应本次检查，不代表后续版本始终符合相同结论。

## 已修复的问题

- 导入备份的分组 ID 可进入 HTML 属性而未转义，形成 HTML 注入。分类渲染中的 `id` 和 `aria-labelledby` 已增加转义。生产 CSP 对内联脚本的限制不能代替输出转义。
- 学术前沿与绘图阅读器对畸形 URL hash 解码时可抛出 `URIError`，导致相关初始化或打开流程中断。已为 hash 解码加入失败处理。此项属于健壮性问题。

## 验证与观察

- `npm audit --json` 未报告已知漏洞。此结果取决于当时的依赖版本与公告数据库。
- 反馈接口测试验证了私有 Blob 写入、字段白名单、HTTP(S) URL 校验、URL 凭据拒绝、同站 Origin、内容类型、64 KB 请求上限、突发节流和存储失败反馈；7 项测试通过。测试中仅使用合成数据与测试用配置。
- Prompt 正文与填空内容、摘要、示例代码及主要标题在进入 HTML 时经过转义。外部搜索标签页在跳转前切断 `opener`；工作台内部导航限制为同源页面白名单。
- 当时检查的 43 个 SKILL 仓库名和 18 个 Prompt 来源仓库名均符合预期格式。3,177 个论文链接及 537 个绘图相关链接中未发现危险协议或内嵌 URL 凭据。文档只记录数量，不保存用户内容或私有配置。
- 仓库历史检查覆盖 24 个提交和 234 个文本对象，未发现凭据匹配项或被追踪的 `raw/` 私人原始资料归档。扫描结果仅说明该次检查覆盖范围；公开提交前仍应复核实际暂存内容。
- 从生产页面提交了三条 SKILL 推荐和一条站点推荐，四次均返回 HTTP 201；通过服务端凭据逐条读回 Private Blob，核对内容一致，匿名读取均返回 HTTP 403。测试凭据不进入仓库。

## 保留的边界

反馈接口没有公开读取端点，记录保存在 Private Blob；单实例节流不等同于全局限流。第三方网页、出版社接口与独立画布的实现不在本仓库审查范围内。

浏览器本地数据不会自动跨浏览器或跨域名迁移，应由用户备份。第三方素材的版权与再分发许可属于单独的审核事项，见 [第三方声明](../THIRD_PARTY_NOTICES.md)，不能从技术安全检查或仓库公开状态推导出授权。
