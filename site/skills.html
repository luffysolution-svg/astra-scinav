科研 SKILL

Skill 是给 AI 智能体的能力包：一个含 SKILL.md 的文件夹，装上后 Claude Code 等工具会在需要时自动调用。这里收录 GitHub 上面向科研的开源 Skill 仓库，附安装命令。

怎么安装 Skill？
  • Claude Code 插件市场：在 Claude Code 里运行 /plugin marketplace add 作者/仓库，再用 /plugin install 插件名@市场名 安装。插件名以各仓库说明为准，卡片里已列出。
  • 手动安装：把含 SKILL.md 的文件夹复制到 ~/.claude/skills/（所有项目可用）或项目内的 .claude/skills/（随项目共享）。
  • 其他工具：部分其他 Agent 工具也兼容 SKILL.md 格式，安装目录以各工具文档为准。
  • 安全提示：Skill 可以携带并执行脚本，安装前请先浏览仓库内容，只装来源可信的 Skill。
